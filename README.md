# BoxApps
This is the brains of the custom app system. This Dll loads, manages and creates the app.

## Question & Answers:

- How do I use BoxApps?

  -> Install the dll from releases and place it inside your plugins folder. To get apps, run your game then go to: `Gorilla Tag\BepInEx\MonkePhone\Apps` and place the .app file inside.

- Is this a MonkePhone Fork?

  -> Unlike our other MonkePhone projects which have been forks, this project is a separate mod which credits Dev9998 the original creator in the areas which are necessary.

- Who can create Apps?

  -> Anyone can create apps for MonkePhone. We have designed the system so its easy to use. Install the unity project from the "MonkePhoneUnityProject" repository and follow the documentation.
